# 🤖 Telegram Проджект Менеджер Бот

Интеллектуальный Telegram-бот для управления проектами по методологии Agile с интеграцией ИИ.

## 🚀 Возможности

### 📊 Daily Standup Автоматизация
- Автоматические напоминания о daily standup
- Сбор статусов команды (что делал вчера, планы на сегодня, блокеры)
- Трекинг настроения команды
- Автоматическая генерация сводок

### 🤖 ИИ Интеграция
- Голосовые команды с распознаванием речи
- Умный анализ статусов команды
- Автоматические рекомендации по улучшению процессов
- Генерация отчетов с помощью GPT

### 🎯 Управление Проектами
- Создание и управление проектами
- Трекинг задач и спринтов
- Управление командой и ролями
- Интеграция с внешними сервисами

### 📈 Отчетность и Аналитика
- Ежедневные и еженедельные отчеты
- Анализ продуктивности команды
- Выявление блокеров и рисков
- Метрики настроения команды

## 🛠 Установка

### Предварительные требования
- Node.js 18+ 
- Telegram Bot Token
- OpenAI API Key

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd project-manager-bot
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Скопируйте `env.example` в `.env` и заполните необходимые значения:

```bash
cp env.example .env
```

Обязательные переменные:
```env
BOT_TOKEN=your_telegram_bot_token_here
OPENAI_API_KEY=your_openai_api_key_here
ADMIN_CHAT_ID=your_admin_chat_id
SUMMARY_CHAT_ID=your_summary_chat_id
```

### 4. Запуск
```bash
# Development
npm run dev

# Production
npm run build
npm start
```

База данных SQLite3 создастся автоматически при первом запуске в папке `data/bot.db`.

### 5. Настройка команд автокомплита (опционально)
```bash
# Настроить команды для автокомплита в Telegram
npm run setup-commands
```

После этого при вводе `/` в чате с ботом будут показываться все доступные команды с описаниями.

## 📱 Использование

### Основные команды

#### 🔧 Базовые команды
- `/start` - Регистрация и начало работы
- `/help` - Справка по всем командам
- `/profile` - Настройка профиля
- `/team` - Просмотр состава команды

#### 📊 Daily Standup
- `/standup` - Запуск daily standup для команды
- `/mystatus` - Мой статус на сегодня
- `/teamstatus` - Статус всей команды

#### 🚀 Проекты
- `/projects` - Список активных проектов
- `/project <название>` - Создать новый проект

#### 🤖 ИИ команды
- `/ai <вопрос>` - Задать вопрос ИИ
- `/analyze` - Анализ состояния команды
- `/summary` - Генерация отчета

#### 👑 Админские команды
- `/setrole @username <роль>` - Изменить роль пользователя
- `/promote @username` - Повысить пользователя до администратора
- `/roles` - Просмотр ролей всех участников команды

**Доступные роли:**
- `admin` - Администратор (полные права)
- `project_manager` - Проджект менеджер (управление командой)
- `developer` - Разработчик
- `tester` - Тестировщик

### Автоматические функции

#### ⏰ Ежедневные напоминания
- **09:00** - Автоматическое напоминание о daily standup
- **12:00** - Напоминание тем, кто не отчитался

#### 📊 Еженедельные отчеты
- **Пятница 17:00** - Автоматическая генерация еженедельного отчета

### 🎤 Голосовые команды
Просто отправьте голосовое сообщение боту, и ИИ автоматически:
1. Распознает речь
2. Определит намерение
3. Выполнит соответствующую команду

## 🏗 Архитектура

```
src/
├── config/          # Конфигурация приложения
├── services/        # Бизнес-логика
│   ├── database.service.ts    # Работа с SQLite3
│   ├── ai.service.ts         # ИИ интеграция
│   └── project.service.ts    # Управление проектами
├── commands/        # Команды бота
│   ├── basic.commands.ts     # Базовые команды
│   ├── standup.commands.ts   # Daily standup
│   ├── project.commands.ts   # Проекты
│   ├── ai.commands.ts        # ИИ команды
│   └── admin.commands.ts     # Админские команды
├── middleware/      # Middleware для бота
├── cron/           # Автоматические задачи
└── utils/          # Утилиты
```

## 🗄 База данных SQLite3

### Основные таблицы
- `users` - Пользователи команды
- `projects` - Проекты
- `sprints` - Спринты
- `tasks` - Задачи
- `daily_status` - Ежедневные статусы
- `blockers` - Блокеры

База данных создается автоматически при первом запуске. Файл базы данных сохраняется в `data/bot.db`.

## 🔧 Конфигурация

### Настройка Telegram бота
1. Создайте бота через [@BotFather](https://t.me/botfather)
2. Получите токен и добавьте в `.env`
3. Настройте команды бота автоматически:
```bash
npm run setup-commands
```

Или вручную через [@BotFather](https://t.me/botfather):
```
start - Начать работу с ботом
help - Справка по командам
standup - Daily standup
projects - Управление проектами
team - Состав команды
ai - ИИ помощник
profile - Настройки профиля
setrole - Изменить роль пользователя (админ)
promote - Повысить до администратора (админ)
roles - Просмотр ролей команды (админ)
```

### Настройка первого администратора
```bash
# Назначить первого администратора
npm run setup-admin
```

### Настройка OpenAI
1. Получите API ключ на [platform.openai.com](https://platform.openai.com)
2. Добавьте ключ в переменную `OPENAI_API_KEY`
3. Выберите модель (рекомендуется `gpt-4`)

### Настройка чатов
- `ADMIN_CHAT_ID` - Основной чат команды для уведомлений
- `SUMMARY_CHAT_ID` - Отдельный чат для отчетов и аналитики
